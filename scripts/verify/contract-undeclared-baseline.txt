# Codes emitted by Rust with no declaration in src/shared/contracts/**.
#
# The rule this file encodes: DECLARED = an addressable discriminator the
# frontend may branch on. BASELINED = diagnostic detail text that only ever
# rides `status.details` or the tail of a thrown `Err(String)`. If you find
# yourself wanting to branch on a code listed here, that is the signal to
# declare it and delete its line — not to read it out of `details`.
#
# Ratchet, not a suppression list. This file may only SHRINK: a listed code that
# gains a contract declaration FAILS the verifier until the line is deleted.
# A newly emitted code that is not listed here fails immediately.
#
# Blank lines and `#` comments ignored. One code per line, sorted within groups.
