# Contract value exports (const / function) with no runtime consumer.
#
# Why this file exists: a green verifier used to mean "this string appears in
# this file", never "the runtime reads it". `src/shared/contracts/telemetry.ts`
# was validated field-by-field for months while every hook imported a private
# fork instead. This ratchet is what makes the check count mean something.
#
# CONSUMED means one of: referenced by a non-test file outside its own module,
# or carrying a locale key under a KNOWN_DYNAMIC_PREFIX (i18n-keys.mjs) so the
# values are looked up dynamically. A test-only reference does NOT count — the
# telemetry fork had tests too, and they passed against the wrong shape.
#
# Ratchet, not a suppression list. This file may only SHRINK: a listed symbol
# that gains a consumer FAILS the verifier until the line is deleted. A newly
# unconsumed value export that is not listed here fails immediately.
#
# Format: `file.ts SYMBOL`. Blank lines and `#` comments ignored.

# Declared 2026-08-13 alongside the codes Rust already emits. Nothing catches
# these yet — they are thrown Err(String) prefixes with no handler on the
# frontend. Each line disappears when something first renders that failure.

display.ts DISPLAY_COMMAND_ERRORS
lighting.ts LIGHTING_COMMAND_ERRORS
preview.ts PREVIEW_COMMAND_ERRORS
